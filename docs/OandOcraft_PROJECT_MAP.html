OandOcraft Project Map

Interactive control board for the O&O workplace planner: product direction, UI polish, Supabase data, main-site integration, testing, security, operations, and launch gates.

Target: https://oando.co.in/OandOcraft/
Model: bounded Vite SPA under main-site subpath
Scope: one O&O workspace with named access
UI bar: SmartDraw-like, sharp, professional

Product Mandate

all phases one workspace named access

OandOcraft is a controlled O&O workplace planning product, not a generic floor-plan demo. The app must support planning, seating, assignments, admin recovery, reporting, and controlled access for internal and approved external users.

UI Standard

priority phase 3 phase 4
  • Fix the broken compass/minimap control and verify it does not overlay awkwardly on the canvas.
  • Sharpen UI corners across panels, cards, toolbars, menus, modals, and buttons.
  • Keep cards and dense controls at 8px radius or less.
  • Make the editor feel closer to SmartDraw, Lucidchart, and Visio-class planning tools.

Toolbars And Admin HUD

started dockable admin stats
  • Dockable toolbar foundation exists and should expand to every toolbar that benefits from movement.
  • Admin users need live stats for object count, assignments, save state, conflicts, and office health.
  • Toolbar positions should persist and expose a reset-to-default command.

Block Library

MillerKnoll Steelcase BIMobject gaps
  • Use manufacturer references for proportions and typologies.
  • Redraw into one OandOcraft top-view SVG/Konva style.
  • Prioritize workstations, offices, meeting tables, booths, lounge, reception, storage, and facilities.

Supabase Data

phase 2 seed:verify
  • Seeded offices must include real objects, not headings-only data.
  • Verify floors, walls, rooms, doors, windows, desks, furniture, employees, annotations, neighborhoods, and assignments.
  • Capture hosted table counts before and after full-data work.

Main-Site Integration

phase 5 /OandOcraft/
  • Build with npm run build:oando.
  • Serve dist/ under /OandOcraft/.
  • Rewrite nested client routes to /OandOcraft/index.html.
  • Keep CSS and JavaScript isolated from the main site.

Quality Gates

phase 6 release gate
  • npm run lint
  • npm run test
  • npm run build
  • npm run build:oando
  • npm run audit:pages when available

Operations

rollback runbook
  • Keep previous production dist/ artifact available for rollback.
  • Document broken route, broken auth, bad seed, and failed save recovery.
  • Record owner sign-off before launch.
