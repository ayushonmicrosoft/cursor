  • Evaluate later: Floor1's 3D preview, but only as a lazy-loaded optional mode with build, route, and bundle checks.

Command Surface

  • npm run dev starts Vite development.
  • npm run build runs TypeScript build and Vite build.
  • npm run build:oando builds for the `/OandOcraft/` production subpath.
  • npm run lint, npm run test, and npm run audit:pages are quality gates.
  • npm run seed:pull, npm run seed:counts, and npm run seed:verify support hosted/local Supabase data work.

Client State Model

  • canvasStore owns viewport, zoom, tools, and grid behavior.
  • elementsStore owns canvas objects and undo/redo history.
  • floorStore owns floor order, active floor, and per-floor element snapshots.
  • projectStore owns save state, optimistic-lock metadata, conflicts, and office identity.
  • employeeStore, insightsStore, collaborationStore, and uiStore cover people, analysis, collaboration groundwork, and UI chrome.

RLS, RPC, And Triggers

  • RLS helper functions include is_team_member, is_team_admin, office_perm_role, and has_office_perm.
  • RPC functions include accept_invite, create_team, preview_invite, save_office_force, export_user_data, and account-deletion helpers.
  • Triggers create profiles, default team/office ownership, normalize emails, sync profile email changes, and bump office timestamps.
  • Admin office control is intentionally handled in policy and client permission behavior, not by anonymous share-first workflows.
