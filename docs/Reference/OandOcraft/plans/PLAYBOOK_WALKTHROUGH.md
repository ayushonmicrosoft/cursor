# OandOcraft Playbook Walkthrough

## Step 1 - Bootstrap
- Confirm branch/worktree status.
- Load current docs and active issues.
- Lock immediate acceptance criteria.

## Step 2 - Analyze
- Read route/component/store/repository chain.
- Identify where state is authoritative.
- List risks and invariants.

## Step 3 - Implement
- Follow existing patterns unless replacement is explicit scope.
- Preserve permissions and sync behavior.
- Add clear empty/error/loading states.

## Step 4 - Validate
- Run lint, tests, and build.
- Verify desktop and mobile breakpoints on touched screens.
- Check keyboard/focus accessibility for changed controls.

## Step 5 - Release
- Record change summary and residual risk.
- Keep rollback reference ready.
- Close checklist items with owner/date.
