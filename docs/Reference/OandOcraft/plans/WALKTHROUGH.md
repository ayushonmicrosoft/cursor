# OandOcraft Walkthrough

## 1. Bootstrap
- Confirm the repo truth from the docs and source files.
- Verify which docs are canonical and which are stale.
- Establish the target folder structure before editing.

## 2. Analyze
- Read the current routing, stack, workflow, and operations references.
- Identify what belongs in the master plan and what belongs in sub-plans.
- Separate narrative docs from executable checklists.

## 3. Implement
- Write the master plan and five sub-plans.
- Expand the UI error-display and block-library reference docs.
- Regenerate or update the HTML mirrors.

## 4. Validate
- Check that links and references resolve to the new structure.
- Confirm the HTML mini site can be opened directly.
- Ensure the docs align with current app truth and operations.

## 5. Release
- Keep rollback-friendly copies of the docs artifacts.
- Remove stale references and duplicate old plan sources.
- Record the final canonical doc map for future work.
