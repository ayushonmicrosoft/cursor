Engine Model

  • engine route selects renderer path.
  • map is production editor flow.
  • pixi is isolated experimental flow.
  • In-map viewMode controls 2d vs 2.5d only.
Do not document Pixi as a viewMode value.

Save / Sync

  • Autosave debounce: 2000 ms.
  • Optimistic save: saveOffice(..., loadedVersion).
  • Conflict overwrite: saveOfficeForce(...) via RPC.
  • Retry backoff: 2s, 5s, 15s, 30s.

version, elements, employees, departmentColors, floors, activeFloorId, settings, seatHistory, neighborhoods, annotations

Guards

  • ProjectShell currently seeds currentOfficeRole = 'edit' after office load.
