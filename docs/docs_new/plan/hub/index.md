# OandOcraft Plan Index

_Last updated: 2026-05-02_

This folder is the active planning workspace for the OandOcraft overhaul.

Use it as the single planning hub for the canonical narrative, phase execution, and published HTML views.

## Folder map
- `OandOcraft_PLAN.md` — canonical root plan and navigation hub
- `OandOcraft_PLAN.html` — HTML mirror of the canonical root plan
- `phase-1-foundation.md` — truth, archive hygiene, and docs alignment
- `phase-2-catalog.md` — generated catalog, workflow validation, and internal deployment
- `phase-3-rollout.md` — external rollout, renderer expansion, and 2.5D / 3D direction
- `cursor-planning-guide.md` — practical guide for planning, building, and auditing work in Cursor
- `plan-site/` — presentation site for the canonical plan narrative
- `html-version/` — standalone HTML-only render of the canonical plan

## Organization rules
- Keep the root plan focused on cross-phase truth, navigation, and operating rules.
- Keep phase files focused on execution details for their phase only.
- Update the matching HTML file whenever a Markdown plan file has an HTML mirror.
- Treat anything in archive folders as historical unless a file explicitly says otherwise.
- Prefer small, explicit edits over rewriting unrelated plan sections.
