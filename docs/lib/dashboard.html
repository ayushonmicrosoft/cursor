Library model

  • One row per block record in Postgres.
  • Fields include model name, category, source tier, canonical flag, and provenance.
  • SVG assets and previews live in storage, not the table.
  • The sidebar loads and updates records through the shared Supabase client.

Shape system

  • Fast-create shapes for rectangles, circles, lines, arrows, callouts, and text.
  • Variants are explicit so future renderers can distinguish geometry.
  • The UI now supports a dedicated quick-add panel for shape creation.
  • Shape entries are aligned with the element library model.
