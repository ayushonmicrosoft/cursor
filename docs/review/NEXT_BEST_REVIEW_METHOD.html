Floorcraft Review Playbook

Next-Best Review Method

A practical Windows PowerShell workflow to replace CodeRabbit when the CLI cannot run locally. Use it from C:\Floorcraft\Floorcraft for deterministic review evidence plus focused manual checks.

1. Prove scopeUse Git status, diff stats, and whitespace checks before reading behavior.
2. Run confidence checksBuild, lint, test, audit, and optionally smoke routes with Playwright.
3. Review manuallyFocus on React, Pixi, Konva, Supabase, data safety, and user-visible regressions.

Why CodeRabbit Is Blocked

  • The CodeRabbit CLI was not installed or available on PATH.
  • The installer path required sh.
  • No Bash-compatible shell was available in this Windows environment.
  • The project can still be reviewed safely with Git, npm scripts, Vitest, ESLint, audit checks, optional Playwright smoke tests, and manual diff review.

Recommended Replacement Stack

  1. Git scope review: confirm exactly which files changed and avoid unrelated dirty files.
  2. Static confidence: run TypeScript/Vite build and ESLint.
  3. Test confidence: run full or targeted tests matching the changed area.
  4. Dependency confidence: run npm audit and prioritize reachable production issues.
  5. Runtime confidence: optionally run local preview and route smoke checks.
  6. Manual diff review: inspect behavior, data safety, React lifecycle, canvas rendering, Supabase access, and regression risk.
  7. Artifact capture: save outputs and review notes for reproducibility.

PowerShell Commands

Start and create artifacts

Set-Location C:\Floorcraft\Floorcraft
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
$artifactDir = "docs\review\artifacts\$stamp"
New-Item -ItemType Directory -Force -Path $artifactDir | Out-Null

Git scope

git status --short | Tee-Object -FilePath "$artifactDir\git-status.txt"
git diff --stat | Tee-Object -FilePath "$artifactDir\git-diff-stat.txt"
git diff --name-status | Tee-Object -FilePath "$artifactDir\git-diff-name-status.txt"
git diff --check | Tee-Object -FilePath "$artifactDir\git-diff-check.txt"
git diff -- . ':!package-lock.json' | Tee-Object -FilePath "$artifactDir\git-diff-no-lockfile.patch"

Build, lint, format, tests

npm run build 2>&1 | Tee-Object -FilePath "$artifactDir\npm-build.txt"
npm run lint 2>&1 | Tee-Object -FilePath "$artifactDir\npm-lint.txt"
npm run format:check 2>&1 | Tee-Object -FilePath "$artifactDir\npm-format-check.txt"
npm test 2>&1 | Tee-Object -FilePath "$artifactDir\npm-test.txt"

Targeted tests and audit

Get-ChildItem -Path src -Recurse -Include *.test.ts,*.test.tsx,*.spec.ts,*.spec.tsx | Select-Object -ExpandProperty FullName
npm exec vitest run src\components\editor\Canvas\AlignDistributeToolbar.test.tsx 2>&1 | Tee-Object -FilePath "$artifactDir\vitest-targeted.txt"
npm audit --omit=dev 2>&1 | Tee-Object -FilePath "$artifactDir\npm-audit-prod.txt"
npm audit 2>&1 | Tee-Object -FilePath "$artifactDir\npm-audit-all.txt"
Avoid npm run format, npm audit fix, or dependency updates during review unless the task explicitly allows mutation.

Optional Playwright Route Smoke

Use this for routing, auth shells, dashboard, editor, canvas, or build-output changes. Authenticated team/office routes need a seeded session or test account; otherwise verify intentional redirects.

npm run build
$preview = Start-Process -FilePath npm -ArgumentList 'run','preview','--','--host','127.0.0.1','--port','4173' -PassThru -WindowStyle Hidden
Start-Sleep -Seconds 5
@"
const { chromium } = require('playwright');
(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  const routes = ['/', '/login', '/signup', '/forgot', '/help', '/docs', '/dashboard'];
  for (const route of routes) {
    const response = await page.goto(`http://127.0.0.1:4173${route}`, { waitUntil: 'domcontentloaded' });
    console.log(`${route} ${response ? response.status() : 'NO_RESPONSE'} ${await page.title()}`);
  }
  await browser.close();
})();
"@ | Set-Content -Path "$artifactDir\route-smoke.cjs"
node "$artifactDir\route-smoke.cjs" 2>&1 | Tee-Object -FilePath "$artifactDir\playwright-route-smoke.txt"
Stop-Process -Id $preview.Id -ErrorAction SilentlyContinue

Manual Diff Checklist

Scope and React

  • Diff matches the requested behavior and avoids unrelated rewrites.
  • Hooks are unconditional, dependencies are correct, and effects clean up listeners, timers, subscriptions, observers, and canvas resources.
  • Zustand state changes preserve immutability and avoid stale closures.
  • Loading, empty, error, permission, route-param, and query-param states are handled.

Pixi and Konva

  • Pixi apps, textures, containers, handlers, and ticker callbacks are disposed on unmount.
  • Pixi remains isolated from the production Konva route unless intentionally bridged.
  • Zoom, pan, hit testing, resize, selection, snapping, measuring, and overlays remain correct.
  • Canvas updates avoid unnecessary main-thread blocking and excessive React rerenders.

Supabase and Data Safety

  • Calls are scoped by authenticated user, team, office, or tenant as appropriate.
  • RLS is relied on for enforcement, not client filters alone.
  • Inserts, updates, and deletes target explicit rows and columns.
  • Destructive actions are confirmed, reversible, or tightly scoped.
  • Secrets are not exposed in client code, logs, review artifacts, or exports.

Security, Performance, UX

  • User-controlled values render safely and exports include only intended data.
  • Auth redirects and password reset flows avoid open redirects and token leakage.
  • Large lists and canvas interactions remain responsive.
  • Mobile and narrow-screen behavior degrades gracefully.
