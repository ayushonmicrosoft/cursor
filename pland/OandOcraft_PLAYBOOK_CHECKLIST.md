# OandOcraft Playbook Checklist

## Foundation
- [ ] Confirm route map, role model, and environment contract.
- [ ] Capture baseline screenshots and issue notes for changed surfaces.
- [ ] Lock acceptance criteria before implementation starts.

## UX and Accessibility
- [ ] Fix contrast and focus issues in high-traffic routes.
- [ ] Enforce `>=48px` targets on actionable controls.
- [ ] Eliminate horizontal overflow at `320px` in docs and app views.

## Quality and Release
- [ ] Run lint, tests, and build; record failures and fixes.
- [ ] Review audit artifacts and close critical findings.
- [ ] Complete release and rollback checklist and signoff note.
