RBAC Roles

👑 Owner

Full access — delete office, manage members, overwrite any change, impersonate via admin banner.

✏️ Editor

Move elements, assign seats, edit walls, export. Cannot manage team membership.

👤 HR Editor

Edit employee roster, add annotations. Cannot move canvas elements.

📐 Space Planner

Rearrange furniture and walls but not edit the employee roster.

👁 Viewer

Read-only. PII redacted via redactEmployee.ts. Can see seat map colors and reports.
