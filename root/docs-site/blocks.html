Block Categories at a Glance

📐 Tables (4)

Rect 120×60, Conference 240×80, Round 100², Oval 140×90. Auto-compute SeatPosition[] around perimeter. 4–14 default seats.

🖥 Desks (7)

Desk, Hot-Desk, L-Shape, Cubicle, Workstation (4-slot sparse), Private Office, U-Shape Office. All assignable — get sequential deskId.

🏢 Rooms (3)

Conference Room (cap 8), Phone Booth, Common Area. Non-assignable. Store roomName / areaName.

🪑 Seating (4)

Office Chair 24², Armchair 60², Couch 150×60, Sofa 200×80. Decorative — not assignable.

🧱 Structure (6)

Wall (arc bulge), Door, Window, Column 40², Stairs 120×80, Elevator 100², Divider 120×4.

🍽 Facilities (5)

Reception 180×90, Kitchen Counter 200×60, Fridge 70², Whiteboard 140×20, Counter 120×36.

✏️ Primitives (5)

Rect Shape, Ellipse, Line, Arrow, Free Text. Plus Custom SVG upload (sanitized, max 50KB).

🌿 Furniture (4)

Sofa, Plant 40², Printer 60×50, Whiteboard 180×20. Non-assignable visual props.

Library Drag-Drop System

PixiJS v8 — Engine Upgrade

⚠️ Konva Bottleneck

Canvas 2D renderer. Drops frames at 300+ elements with overlays. Large open-plan floors feel sluggish on drag.

✅ PixiJS v8 Wins

WebGL — handles 10,000+ sprites at 60fps. V8 has @pixi/react bindings. Migration guide already bookmarked in Block sites.md.

🔧 Implementation

Install pixi.js@8. Create PixiStage.tsx alongside Konva. Wire to viewMode: 'pixi' in uiStore. Render elements as PixiJS Graphics.
