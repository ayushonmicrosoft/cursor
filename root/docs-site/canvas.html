Renderer Components

🧱 WallRenderer

Polylines with per-segment arc bulge. Supports solid, glass, half-height, demountable wall types + dashed/dotted stroke patterns.

🚪 DoorRenderer

Wall-attached. Renders swing arc. Snaps to nearest wall, tracks parent wall position on move.

🪑 DeskRenderer (33KB)

Straight, L-shape, cubicle variants. Draws seat badge, department color stripe, assignment state.

🏢 RoomRenderer

Conference rooms, phone booths, common areas, private offices. Room-name label inside bounds.

📐 TableRenderer

Rect, conference, round, oval. Computes SeatPosition[] around perimeter via seatLayout.ts.

✨ ElementRenderer (18KB)

Dispatcher — switch on element.type to route to the correct renderer. Also handles drag, hover, click events.

📍 SeatLabel (28KB)

Floating name + dept color badge above each assignable seat. Style picker, status icons, hover card trigger.

🗺 Minimap (13KB)

Always-on thumbnail. Viewport rect is draggable — pans the main stage. Updates on every element change.
