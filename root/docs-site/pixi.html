Migration Strategy — Bridge, Not Big Bang

PixiJS runs parallel to Konva. Each phase ports more renderers until Konva is fully removed.

Phase 1 — What's Live Now

📦 PixiStage.tsx

At src/components/editor/Canvas/PixiStage.tsx. Creates a PixiJS Application on a canvas element. All floor plan elements rendered as colored rectangles with correct position, size, and rotation.

🖱 Pan & Zoom

Mouse drag pans the world container. Scroll wheel zooms centred on cursor using exponential factor matching Konva's ZOOM_WHEEL_SENSITIVITY. Multi-element select via Ctrl/Cmd+Click.

🔗 Store Integration

Subscribes to useElementsStore — re-renders on every element change. Click events write through useUIStore.setSelectedIds() so selection stays in sync with Konva mode.

⚡ TopBar Toggle

⚡ Pixi β button added to the view-mode group in TopBar. Cycles between Konva (2D) and PixiJS. Zero changes to Konva rendering path.

🔒 Type Safety

uiStore.viewMode extended to '2d' | '2.5d' | 'pixi'. togglePixiMode() convenience action added. MapView switches on the new value.

⏳ Not Yet in Phase 1

Wall arc curves, door swing arcs, seat label badges, dept color coding, alignment guides, minimap, annotation pins, custom SVG shapes, drawing tools.
